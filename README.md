# 🌤️ Weather Forecast App

A responsive web application built using HTML, CSS, and JavaScript that fetches and displays real-time weather information and forecasts for any city.

---

## 📁 Repository Structure

* `index.html` - The structural markup and layout for the user interface.
* `style.css` - Custom styling, layout responsiveness, and visual theme.
* `script.js` - JavaScript logic for handling API requests, event listeners, and dynamic UI updates.

---

## ⚡ Features

* **Real-time Weather Data:** Displays temperature, weather conditions, humidity, and wind speed.
* **City Search:** Allows users to search for live weather metrics across global locations.
* **Responsive Design:** Optimized for both desktop and mobile screens.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **API Integration:** OpenWeatherMap API (or REST Weather API)
